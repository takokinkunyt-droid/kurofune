# シーズン2「クリックとかけら」設計メモ

決まったことの控え。数字は仮（調整前提）。

## 画面
- ホーム廃止。開いたら黒船の画面。
- 空と海が端末の時計で 朝(5-10)・昼(10-16)・夕方(16-19)・夜(19-5) に移る。境目は30分かけて移る。手動で固定もできる。
- スマホ：下から引き出す棚（施設／強化／生産）。PC：右に棚を常設、メニューは引き出し式。
- アイコンは絵文字。

## クリック
- 1クリック ＝ 固定分 ＋ KpS × 連動率（初期 1%）。
- 連動率を上げる手段：蒸気機関の改良（隻数・周回内）、水夫×海水、高圧ボイラー（木の鍛冶）。
- バーストはそのクリックに倍率を掛ける。

## かけら
- 総数 ＝ floor( cbrt(シーズン中に稼いだ合計 / 1e6) × (1 + かけらボーナス) )。
  転生でもらえるのは「総数 − これまでにもらった数」。
- 目安：1億隻→4個、100億→21個、1兆→100個、100兆→460個。
- かけらボーナスは足し算（かけらⅠ+10%、Ⅱ+20%、Ⅲ+30%、泉+5%×8段）。最大でも合計2倍程度。
- 持っているだけで効く仕組み（③）は見送り。

## 転生
- ランキングは「シーズン中に稼いだ隻数の合計」で比べる（転生しても順位が落ちない）。
- 転生ボタンの確認では「もらえるもの」（かけら数・次に開くもの）を一覧で見せる。
- 再出航ブーストは入れない。演出は既存のものを使う。
- 転生の回数は、一部スキルの追加条件になる（例：水夫は転生5回）。

## 金船
- 木で開く。最初は出ない。
- 出る間隔はほぼ一定（約6分、見張り番で5分）。
- 効果は KpS 基準にそろえる：
  - 備蓄：KpSの10分ぶん（持っている隻数の10%まで）
  - 黄金時代：77秒 生産×7
  - 777倍：5秒 クリック×777（クリックがKpS連動なので強い）

## スキルの木（クッキークリッカーの天国のアップグレード式）
- 真ん中から四方に広がる地図。前提を買うと次が姿を現す。前提が2つのスキルもある。
- 鍛冶（何度でも上げられる）も木の中に混ぜる。1段ごとに値段×1.5。
- 一覧は index.html の S2_TREE を正とする。
